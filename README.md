# Ficusia Hub

Animation Creator Portfolio & Career Directory. React + Vite, 22 screens across Public Visitor, Creator and Admin (see Wireframe_Ficusia_Hub.pdf).

## Run
    npm install
    npm run dev      # development
    npm run build    # production build in dist/

## Demo accounts
- Creator: any email + any password (opens Riki Oktav's dashboard)
- Admin: an email starting with "admin" + any password

All data is held in memory (front-end demo). Images are in public/img, the CV is in public/files.
